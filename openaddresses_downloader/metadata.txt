about=Downloads address points (number, street, unit, city, district, region, postcode) from OpenAddresses for the current map extent or the polygons of a layer.

    Coverage: about 2,300 sources in 70+ countries, densest in the United States. Where two sources cover the same place, the same address can appear once for each.

    Reads only the map tiles over the area from the single global address file OpenAddresses publishes, so no account is needed and no API calls are made. Needs GDAL 3.8 or later, which current QGIS installers include. No extra Python packages are needed.

    Data licence: every source has its own licence, and many state none. The global file does not say which source each address came from, so a second output, Source licences, lists every source whose coverage touches the area, with its licence, licence URL, who to credit and whether the licence is share-alike. Check them before you publish data made with it. This is an unofficial plugin, not made or endorsed by OpenAddresses.

    Runs as a Processing algorithm, so it also works in models, batch mode and qgis_process.
