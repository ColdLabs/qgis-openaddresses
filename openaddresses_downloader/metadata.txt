about=Downloads address points (number, street, unit, city, district, region, postcode) from OpenAddresses for the current map extent or the polygons of a layer.

    Coverage: about 2,300 sources in 70+ countries, densest in the United States. Where two sources cover the same place, both are returned.

    Reads only the map tiles over the area from the public tile files OpenAddresses publishes per source, so no account is needed. Needs GDAL 3.8 or later, which current QGIS installers include. No extra Python packages are needed.

    Data licence: every source has its own licence, and many state none. Each address carries its source, licence, licence URL, who to credit and whether the licence is share-alike. Check them before you publish data made with it. This is an unofficial plugin, not made or endorsed by OpenAddresses.

    Runs as a Processing algorithm, so it also works in models, batch mode and qgis_process.
